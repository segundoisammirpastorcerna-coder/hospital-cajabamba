# hospital-cajabamba
El sistema permite gestionar pacientes y citas médicas.
## Pruebas unitarias

El proyecto cuenta con cuatro pruebas unitarias automatizadas
utilizando unittest de Python.

Las pruebas verifican:

- Filtrado por especialidad.
- Filtrado por médico.
- Transformación de fechas.
- Ordenamiento de citas por fecha.
Proyecto del Nuevo Hospital de Apoyo Cajabamba.
